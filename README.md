# pyflow — Python 静态分析流程图生成器

把一个 Python 脚本解析成**标准流程图网页**：初始只显示模块入口和未被调用的函数，
点击语句旁的调用标记，在调用点原位置展开被调函数的流程图，可递归展开。

生成的 HTML 自包含（数据 + 布局引擎全部内嵌），浏览器直接打开即可，零依赖、零服务。
分析端只用标准库（`ast` + `tokenize`），无第三方依赖。

## 用法

```bash
python flowgen.py <目标.py> [输出.html]
# 默认输出 flow.html
```

示例：

```bash
python flowgen.py demo_sample.py demo_flow.html
```

## 图上交互

| 操作 | 效果 |
|---|---|
| 左侧函数列表 | 每个函数一项（入口带 ★，当前定位项高亮）；入口点击定位区块，被调用函数点击自动展开图中第一个调用点并滚动过去 |
| 点击 `⊙ 函数名` 金色标记 | 在该调用点原位置展开被调函数流程图；再点收起 |
| 展开图内再次点击 | 递归展开（每个调用点独立渲染副本，互不影响排版） |
| 滚轮 / +- 按钮 | 缩放（平移用拖拽） |
| 左键拖拽 | 平移画布（不触发文本选择） |

画布不显示原生滚动条：内容超出视图就超出，用拖拽查看。

## 图形约定

- 金色胶囊：开始（函数签名 / 模块入口）与结束（函数结束 / 模块结束）
- 矩形：处理语句（原文显示，注释行为绿色斜体）
- 菱形：判断（if/elif 条件、循环条件、异常判定），分支标「是 / 否」
- 红色矩形：`return` / `raise` / `break` / `continue` 终止节点，其后不画回程线
- 青色矩形：嵌套函数定义节点
- 金色虚线框：已展开的函数子图，标题为限定名（嵌套函数如 `save_snapshot.encode`）
- 蓝色回边：循环回边；主流程竖向延伸，分支横向右列延伸，所有连线正交、通道独立不重叠

## 代码与注释显示

语句节点内为源文件**原文行**（仅去前导缩进，不增删换行，行尾注释原样保留）；
语句范围外的独立注释就近挂到下一语句/函数头上方，函数末尾注释挂到函数图尾。

## 测试用例

| 文件 | 覆盖 |
|---|---|
| `demo_sample.py` | if/elif/else、while、for、try/except/finally、early return、docstring、独立入口（生成 `demo_flow.html`） |
| `stress_sample.py` | 多行语句、for-else、break/continue、with、嵌套 def 调用（生成 `stress_flow.html`） |

自举测试：`python flowgen.py flowgen.py self_flow.html` 可分析工具自身（15 个函数，含类与嵌套函数）。

## 实现要点

1. **分析端**（`flowgen.py`）：`ast` 提取语句树（if/elif 链展平、循环、try/handler、with、嵌套 def），
   `tokenize` 收集注释并就近归属，调用图取 `Call(Name)` 匹配本地函数（跳过嵌套作用域），
   统一以限定名定位展开目标，入口 = 未被任何函数调用的 def。
2. **前端布局引擎**（内嵌 JS）：每个语句块返回 `{左延伸, 右延伸, 高, 节点, 连线, 出口}`，
   出口为 `null` 表示路径终止；顺序块轴对齐堆叠，if 分支体「居中优先、超高顶对齐」，
   循环回边走左侧通道、假出口走右侧通道，try 汇流直接横向回中轴（仅当会穿过 try-else 体时才右侧绕行）。

## 已知边界

- 类方法不作为独立函数图分析（其体内的本地函数调用会计入调用图，不影响入口判定）
- 模块级调用（如 `if __name__ == "__main__": main()`）不影响入口判定，`main` 始终作为入口入图
- `match` 语句整块按原文显示，未展开 case 分支
